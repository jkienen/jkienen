**Featured Project**

<tr><td align="center">

<p align="center">
  <img src="./Files/featured-project.png" alt="Full Data Lake graph rendered from the live catalog: Raw endpoints across Crowdstrike, Tenable and VCenter feeding Silver datasets, Audits, Gold indicator files and Automations, color-coded by layer and grouped by project.">

Every automation in production is a decision made on someone's behalf, and when one deletes or closes a record, the only proof it existed goes with it.

This catalog makes the whole chain visible. An AI skill reads each project's code and writes one YAML file per endpoint, rule, audit, indicator and automation. 

It ships with **15+ endpoints** documented as working samples of real automations across CrowdStrike, Tenable and VCenter, and **30+ Gold indicators** built on top of them to track monthly, plus an **Audit layer** that keeps the record of what was acted on after the action erased it at the source.

**Living documentation, written and standardized by AI — every KPI auditable down to the code that produced it, at any moment, with no human upkeep.**
